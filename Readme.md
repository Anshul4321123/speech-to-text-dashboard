# 🎙️ Speech to Text Dashboard

A full-stack web application that combines Nhost authentication with Deepgram's speech-to-text API to provide real-time audio transcription.

## 🌟 Live Demo

**Production URL:** https://speech-to-text-dashboard.anshul04072005.workers.dev

## ✨ Features

- 🔐 **Authentication** (Nhost)
  - Email/Password signup and login
  - Session persistence
  - Email verification
  - Protected dashboard routes

- 🎤 **Speech-to-Text** (Deepgram)
  - Microphone audio capture
  - Real-time transcription
  - Professional processing status indicators
  - Clear transcript display with word count

## 🛠️ Tech Stack

- **Frontend:** React 18 + Vite
- **Authentication:** Nhost (Backend-as-a-Service)
- **Speech-to-Text:** Deepgram API
- **Routing:** React Router DOM
- **Styling:** CSS-in-JS (inline styles)
- **Hosting:** Cloudflare Pages

## 📋 Prerequisites

Before you begin, ensure you have:

- Node.js (v18 or higher)
- npm or yarn
- A [Nhost](https://console.nhost.io/) account
- A [Deepgram](https://console.deepgram.com/) account
